# 英语衡水体字帖生成器

一个完全在本地浏览器运行的英语衡水体字帖生成器。作文内容不会上传到服务器。

## 在线仓库

[SamuelChen-CN/hengshui-handwriting-generator](https://github.com/SamuelChen-CN/hengshui-handwriting-generator)

## 使用方式

1. 确认 `fonts/hengshui.ttf` 存在。
2. 直接双击打开 `index.html`。
3. 在左侧输入或粘贴作文，右侧实时查看 A4 字帖。
4. 点击顶部“打印 / 保存 PDF”，在浏览器打印窗口中保存为 PDF。

项目无需后端、数据库或在线服务。

第一版采用纯本地 HTML、CSS 和 JavaScript，使用浏览器实时预览，并通过浏览器打印功能保存为 PDF。

当前第一版已包含：

- 衡水体 TTF 加载状态提示
- 按英文单词实际测量后换行，避免拆分单词
- 按 A4 纸张可用高度自动分页
- 抄写、临摹、描红和固定 9mm 考试答题卡横线；横线作为第三条基线，字母主体在其上方、g/y 等下伸部分落在线下
- 临摹模式会在每条示范文字后增加一条相邻空白练习横线
- 输入文本末尾的空行会保留为对应的空白横线
- 高级设置支持调整字体大小、字体颜色、横线粗细、行距、横线颜色，以及是否显示横线
- 顶部固定操作栏提供项目名、字体状态和打印按钮
- 打印 / 保存 PDF 时保留横线，保证预览与打印一致
- 示例作文、清空、字符数/单词数统计
- 浏览器打印 / 保存 PDF

## 字体文件

请将衡水体 TTF 文件放在：

`fonts/hengshui.ttf`

如果你的字体文件名称不同，可以直接改名为 `hengshui.ttf`。

## 当前目录

- `index.html`：页面结构
- `style.css`：界面、A4 纸张、字帖和打印样式
- `app.js`：实时预览和基础交互
- `fonts/`：字体资源目录
- `assets/`：预留的图片和图标资源目录
